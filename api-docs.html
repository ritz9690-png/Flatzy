🏠 Flatzy Public API

Live REST API for Nagpur property listings — powered directly by Firestore. Any business (CRM, aggregator, broker platform) can pull Flatzy's verified listings in real time.

Authentication

Every request needs Flatzy's partner API key as a query parameter. This is a Flatzy-issued key (not a Firebase credential) — it's checked server-side, and the underlying Firebase credentials never reach the client or browser.

Why this matters

This turns Flatzy from a standalone website into a data source — other Nagpur-focused platforms and business tools can build directly on top of Flatzy's verified listings.
